# InsightLab One — Onda 3 / Checklist de Aceite

## Critérios de aceite da Onda 3 base
- [ ] schema da agenda aplicado com sucesso
- [ ] módulos de appointments, availability e appointment-blocks presentes
- [ ] DTOs base da agenda funcionando
- [ ] regras mínimas de conflito e bloqueio funcionando
- [ ] cancelamento e no-show respondem
- [ ] disponibilidade básica responde
- [ ] testes unitários iniciais passam
- [ ] testes de integração iniciais passam
- [ ] erros seguem padrão amigável

## Fechamento da Onda 3
A Onda 3 base pode ser considerada concluída quando a agenda estiver funcionalmente estável o suficiente para sustentar o início do atendimento operacional.
