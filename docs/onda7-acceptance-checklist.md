# InsightLab One — Onda 7 / Checklist de Aceite

## Critérios de aceite da Onda 7 base
- [ ] schema de comissão/diferido aplicado com sucesso
- [ ] módulo de commissions presente
- [ ] DTOs base de comissão funcionando
- [ ] regras mínimas de geração e status funcionando
- [ ] bloqueio responde
- [ ] liberação responde
- [ ] comissão respeita modo básico de liberação
- [ ] testes unitários iniciais passam
- [ ] testes de integração iniciais passam
- [ ] erros seguem padrão amigável

## Fechamento da Onda 7
A Onda 7 base pode ser considerada concluída quando comissão, liberação condicionada e diferido avançado estiverem funcionalmente estáveis o suficiente para sustentar a governança ampliada e a preparação do piloto.
