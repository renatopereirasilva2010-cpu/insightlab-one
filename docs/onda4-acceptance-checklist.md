# InsightLab One — Onda 4 / Checklist de Aceite

## Critérios de aceite da Onda 4 base
- [ ] schema do atendimento aplicado com sucesso
- [ ] módulo de attendances presente
- [ ] DTOs base do atendimento funcionando
- [ ] regras mínimas de criação e transição de status funcionando
- [ ] início e finalização respondem
- [ ] cancelamento responde
- [ ] testes unitários iniciais passam
- [ ] testes de integração iniciais passam
- [ ] erros seguem padrão amigável

## Fechamento da Onda 4
A Onda 4 base pode ser considerada concluída quando o atendimento estiver funcionalmente estável o suficiente para sustentar a venda operacional.
