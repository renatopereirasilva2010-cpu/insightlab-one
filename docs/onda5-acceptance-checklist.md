# InsightLab One — Onda 5 / Checklist de Aceite

## Critérios de aceite da Onda 5 base
- [ ] schema da venda aplicado com sucesso
- [ ] módulos de sales e sale-items presentes
- [ ] DTOs base da venda funcionando
- [ ] regras mínimas de criação, itemização e status funcionando
- [ ] recálculo responde
- [ ] pronta para checkout responde
- [ ] cancelamento responde
- [ ] testes unitários iniciais passam
- [ ] testes de integração iniciais passam
- [ ] erros seguem padrão amigável

## Fechamento da Onda 5
A Onda 5 base pode ser considerada concluída quando a venda estiver funcionalmente estável o suficiente para sustentar checkout e pagamento.
